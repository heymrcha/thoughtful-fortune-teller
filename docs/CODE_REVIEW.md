## 3. 브라우저 확인 내역 (Vite 개발 서버, 로컬)

- 홈 → AI 관상: "갤러리"/"카메라" 클릭 시 각각 `갤러리 사진 선택` / `카메라 사진 촬영` input이 열림
- 궁합: 빈 폼 → 버튼 비활성, 내 정보만 입력 → 비활성, 양쪽 입력 → 활성 → 결과(샘플 안내·"상극" 표기) → "전문 상담 받기" → 상담 탭 이동
- 타로: 같은 위치를 8회 뽑아 서로 다른 카드 3종 확인
- MY: 등록된 관계 2 표시
- 연예인 궁합: `<img>` 0개, 이니셜 아바타 표시
- 하단 내비게이션: 현재 탭 `aria-current` 1개, 안전영역 패딩 클래스 적용
- 뷰포트 메타에서 `user-scalable=no` 제거 확인

**확인하지 못한 것**: 실제 카메라·파일 선택창 동작(클릭 대상만 확인), 실기기(iOS)에서의 안전영역 렌더링, 스크린리더 실사용, 모바일 실기기 성능.
